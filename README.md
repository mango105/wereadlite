# 微读lite（wereadlite）· 电纸书精简客户端

给**低性能安卓电纸书**写的微信读书客户端。安装包约 165 KB，默认最低支持 Android 4.2（可另出 Android 4.0 包），不依赖 AndroidX、不依赖 WebView、不用 Gradle，界面 100% 代码直绘，专注把「读」这一件事做顺。

> ⚠️ 非官方客户端，与腾讯 / 微信读书官方无关，仅供个人学习与自用。微信读书接口无公开文档，随时可能因服务端调整而失效；请勿用于商业用途或大规模分发。

## 快速开始

### 直接安装

1. 从 [Releases](../../releases) 下载 `wereadlite-0.3.0.apk`（V1 签名，minSdk 17 / Android 4.2+）。
2. 传到电纸书上安装。Android 4.0 设备用带 `-min14` 后缀的包。
3. 首次打开用微信扫码登录；**不登录也能用**：登录页点「跳过登录，先读本地书」，在书架页点「导入」即可读本地 TXT / EPUB。

### 从源码构建

```bash
bash build.sh                  # minSdk 17，产物 dist/wereadlite-0.3.0.apk
MIN_SDK=14 bash build.sh       # minSdk 14，产物带 -min14 后缀
bash tools/selftest.sh         # JVM 解析回归（当前 302 条断言）
```

环境要求：Android SDK（对应 minSdk 的 platform 桩 + build-tools，可用 `ANDROID_HOME` 指定）、JDK 11 以上（跑 R8 与 apksigner，可用 `JDK17` 指定）、python3（工具脚本）。工具链全部自动探测，不需要 Gradle、不需要 Android Studio。

签名口令从环境变量读取：`KS_PASS`、`KS_ALIAS`；不设时用脚本内默认值，仅用于本地自签名。首次构建若没有 keystore 会自动生成一个，**keystore 不会被提交进仓库**。

界面参考稿在 [`微读界面稿预览/`](微读界面稿预览/)（6 张设计稿），真机调试截图与诊断数据不入库。

## 为什么这么小

| 取舍 | 做法 |
| --- | --- |
| 界面 | 100% 代码直绘：没有 XML 布局、没有主题包。`res/` 里只放 5 个密度的 launcher 图标 PNG，界面内图标（返回箭头、勾选、目录、书签、想法气泡等）全部由 Canvas 现画 |
| 依赖 | 只有一个 `libs-zxing.jar`（二维码），其余全部走 Android framework |
| 渲染 | 黑白直绘、无过渡动画。墨水屏本来也不靠中间帧表达状态，去掉动画既省内存又更跟手 |
| 分页 | 自己用 `StaticLayout` 手动分页，不引入任何阅读引擎 |
| 构建 | `javac --release 8` → R8 压缩脱糖 → `aapt2 compile` + `link` → zipalign → apksigner。产物 `classes.dex` 约 290 KB |

## 低版本适配

- `minSdk 17`（Android 4.2）为默认构建；`MIN_SDK=14 bash build.sh` 另出 Android 4.0 可用的包。`targetSdk 28`。
- 编译期用 android-17 桩 jar，写超界的 API 直接编译不过。
- 构建最后一步会把 dex 里**每一个框架方法引用**和 SDK 的 `api-versions.xml` 逐一比对，出现高于 minSdk 的调用就判定失败——低版本适配不靠人肉记忆。
- 运行时存储权限（API 23）用反射调用，dex 里不会留下高版本框架方法引用；反射失败时退回原来的「试列目录」判断，不会在低版本设备上崩。
- 签名只走 V1（JAR）。JDK 的 jarsigner 会写 CMS signedAttributes，Android 4.4 以下的 `JarVerifier` 解析不了，会直接装不上。
- TLS 提供「兼容模式（证书容错）」开关，应对老 ROM 证书链残缺导致书架同步失败。

## 功能

### 书架
- 微信扫码登录，二维码 + 长轮询；登录后用 renewal 续期，一次授权长期有效。
- 书架同步、封面拉取与本地缓存、公开/私密阅读统计。
- 登录过期会明确提示并带回登录页，不会伪装成「书架是空的」。
- 云端同步失败时，本地导入的书照常显示。
- 长按某本进入多选（先选中它），点「选择」进入时默认一本都不勾；可批量移出书架。

### 发现（轻量书城）
- 最近阅读、猜你喜欢（可换一批）、热门书目。
- 搜索书名/作者，带输入联想。
- 书籍详情页：评分与评分分布、点评人数、字数、出版方、简介、是否可读、加入书架、本书已读时长。
- 有意不做排行榜。

### 阅读
- 云端书与本地书统一在同一套分页器里读。
- 翻页：左侧 28% 区域上一页、右侧 28% 下一页、中间唤出工具条；音量键翻页（可在设置关闭，关掉后恢复系统音量行为）；方向键 / Space / PageUp / PageDown 同样有效。
- 工具条分上下两条：**顶部**为加书签 / 笔记 / 目录 / 立即同步进度，顶部常显的只有章节名（书名页脚已有，不重复）；**底部**为返回书架 / 目录 / 阅读进度 / 收起 / 字体设置。
- 目录、章内进度滑杆、上一章下一章跳转；页码与百分比支持「按整本书累计」和「按章」两种口径。
- 点底部工具条最右侧的 **A** 打开显示样式面板：字号 14–34 pt、边距 4–44 dp、行距 1.08–2.00、**段落首行缩进 4–8 个半角格**（默认 4 格 = 2 个汉字）；「首行缩进 ›」进入段落样式面板，段间距 **0–4 档可调**（只加在段首行，段内行距不受影响）。每个滑杆两侧有 −/ + 圆钮，轻点走一档、按住拖动实时预览、松手记住；拖动预览按上一次重排耗时自适应节流，慢机器上也不会把输入事件拖垮。
- 缩进靠 `LeadingMarginSpan` 只加空白、不往正文插字符，字符偏移和云端进度始终对得上；续页第一行不会被误当成段首再缩一次，原文本身带前导空格的 TXT 只补足到设定宽度，不会叠成双倍缩进。
- 页脚一行：左页码 / 中书名·作者 / 右百分比同排，中间文字按宽度自动省略；正文高度据此重算，页眉只留章节名。
- **书签**：底栏书签图标一键加 / 取消当前位置（同一位置再点一次即取消），「目录 › 书签」页列出全书书签，点条目跳回原处、点 × 删除。书签记的是「章节 uid + 章内字符偏移」，和进度上报、首行缩进共用同一套原文坐标，改字号排版后仍能跳回；目录增删时 uid 找不到会退回存的下标。
- **书签跨设备同步**：在「我」页点「导出书签」生成 JSON 文件，另一台设备用「导入书签」合并。同章同位置（24 字容差）自动去重、不覆盖本地已有书签，每本上限 300 条。走系统文件选择器，不需要存储权限，也不上传任何数据。

### 阅读进度双向同步
- 上行：每次翻页、退出都按网页端协议上报 `/web/book/read`，落库才认 `{"succ":1}`；关书时若开了自动上传，额外补一次快照上传。
- 下行：开书按设置自动拉取云端进度，两个来源一起看——书架接口返回的 `bookProgress[]`，以及 E-Ink 接口的 `GET /book/getProgress`；两边都有时取更新时间较新的那一条。
- 位置比较**以坐标为优先**：先比章节 uid，同章再比章内字符偏移（容差 12 字算同一处），坐标缺失时才退回百分比（2% 阈值），避免「百分比一样但位置差半页」的误判。
- 决策状态机在 `Sync.java`（纯逻辑、可单测）：云端更快就跳转并提示、本地更快就自动上传、两个来源互相矛盾时静默取新（不打扰用户），只有本地明显领先且设置未开自动上传时才提示。
- 上报成功的那一段阅读时长本地直接累加，不用等下一次同步才动；离线翻页会存一份 pending 快照，下次联网补传。
- 开关在「设置 › 阅读 › 进度同步」：开书拉取 / 关书上传两个独立开关，默认关闭，未登录时隐藏。

### 笔记
- 阅读页顶部「笔记」进入覆盖页：书籍卡片（封面 / 已读百分比 / 书签数 / 时长）+「我的书签」列表 +「书友想法」入口。
- 书签条目点一下跳到原文位置，点 × 删除；顶部 ← 返回阅读。
- 书友想法为只读，按页拉取当前章；优先 E-Ink 接口，取不到回退网页接口，缺授权时直接给授权入口。顶部摘录卡片支持长按复制原文。
- 自己写想法 / 划线需要微信读书私有写入接口，暂不支持，界面上如实标注。

### 本地导入
- 支持 TXT 与 EPUB，从应用内的文件选择器导入。
- **EPUB 元数据**：解析 OPF 里的 `dc:title` / `dc:creator` 作为书名与作者（书名页 / 版权页等前置短页保留为目录条目）；提取封面图（`properties='cover-image'` 或 `<meta name='cover'>`），书架卡片与目录标题栏都显示真实封面。
- **EPUB 层级目录**：按 toc.ncx / nav 的书签树分级展示——卷级加粗、章回缩进，点条目直接跳转；封面页跳过不占章节，指向被跳过页的目录项归到后面第一个保留章节。
- 自动分章、清洗书名里的扩展名与多余空格，按书存成 `files/books/<key>/`。
- Android 6+ 首次进入会申请运行时存储权限；权限被拒时列表会给出可点的授权引导，跳系统设置开启即可，回来自动重扫。
- 系统里若有文件管理器，也可用选择器里的「用系统文件管理器选文件」走 `content://` 通道（不需要存储权限），或直接在文件管理器里用「打开方式」把书发给本应用。
- 「跳过登录，先读本地书」进的离线模式只显示本地书，不发网络请求，也不会误报登录过期。

### 书友想法
- 只做入口与只读浏览，按页拉取当前章的书友想法；优先走 E-Ink 接口，取不到再回退网页接口，没有数据就显示空态。
- 不写本地划线和想法，不改动云端笔记。

### 设置与账号
- 设置入口只留一个：书架页右上角齿轮。设置分三页——显示（字号 / 行距 / 边距）、阅读（进度口径、音量键翻页、屏幕常亮、**进度同步**两个开关）、账号（重新登录、兼容模式、关于）。阅读页的 **A** 面板与设置在字号行距上共用同一份偏好。
- 「我」页保持精简：顶部一张阅读统计卡（累计阅读 / 墨水屏阅读 / 本周阅读），下面是书架、同步书架、**数据与备份**、云端功能授权（E-Ink）、关于。书签导入导出与整包备份恢复合并进「数据与备份」一个弹窗，不再单独占行。
- E-Ink 授权独立于网页登录，只有书友想法依赖它；想法页在缺授权时会直接引导去授权。进度与阅读时长走网页接口，不需要这个授权。

## 已知限制

- 不含语音朗读（TTS），不做内置字体切换——按需求明确排除。
- 长章节（十万字级）首次进入要整章排版一次，低端机上仍有几百毫秒到一两秒的停顿；样式拖动已做自适应节流，但首次分页本身省不掉。
- 微信读书网页登录会过期（errCode -2010 / -2012），过期后需重新扫码一次。
- 阅读时长、书友想法依赖 E-Ink 授权；未授权时相应位置留空，不编造数据。
- **书签同步是「导出 / 导入 JSON 文件」的手动方式**：微信读书没有公开的云端书签接口，本项目已实现的协议里也不含书签读写，因此没有做自动云同步。书签只存在设备本地 SharedPreferences 与用户自己导出的文件里。
- **不支持调起本机微信 App 授权登录**：这需要微信开放平台移动应用资质、微信 SDK、包名与应用签名绑定以及服务端换取会话，且电纸书设备通常没有安装微信。现有登录仍是屏上二维码 + 手机微信扫码确认，以及独立的 E-Ink 扫码授权。
- 已在竖屏模拟器与横屏电纸书真机上验证；平板未适配。
