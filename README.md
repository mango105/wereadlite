# 微读lite（wereadlite）· 电纸书精简客户端

给**低性能安卓电纸书**写的微信读书客户端。安装包约 182 KB，默认支持 Android 4.2+（可另出 4.0 包），不依赖 AndroidX / WebView / Gradle，界面 100% 代码直绘，专注把「读」做顺。

> ⚠️ 非官方客户端，与腾讯 / 微信读书官方无关，仅供个人学习与自用。接口无公开文档，随时可能因服务端调整失效；请勿商用或大规模分发。

## 快速开始

```bash
bash build.sh                  # minSdk 17，产物 dist/wereadlite-0.3.0.apk（182 KB）
MIN_SDK=14 bash build.sh       # minSdk 14，产物带 -min14 后缀
bash tools/selftest.sh         # 解析回归（342 条断言）
```

- **安装**：从 [Releases](../../releases) 下载 APK 传到设备；Android 4.0 用 `-min14` 包。
- **登录**：首次微信扫码；也可点「跳过登录，先读本地书」直接导入 TXT / EPUB。
- **构建环境**：Android SDK（platform 桩 + build-tools，可用 `ANDROID_HOME` 指定）、JDK 11+（跑 R8 / apksigner，可用 `JDK17` 指定）、python3。全部自动探测，无需 Gradle / Android Studio。
- **签名**：口令读环境变量 `KS_PASS` / `KS_ALIAS`，不设用脚本默认值（仅本地自签名）；keystore 不入库。
- 界面参考稿在 [`微读界面稿预览/`](微读界面稿预览/)。

## 主要功能

- **书架 / 发现**：扫码登录（一次授权长期有效）；书架同步、封面缓存、公开/私密统计；轻量书城含猜你喜欢、搜索联想、书籍详情，不做排行榜。登录过期会明确提示；云端失败不影响本地书。
- **阅读**：云端书与本地书同一套分页器。左右两侧翻页、中间唤工具条；音量键 / 方向键 / 空格也可翻。目录、章内进度、上下章跳转，页码支持整本累计或按章两种口径。
- **显示样式**：点底栏 **A** 调字号 14–34、边距 4–44dp、行距 1.08–2.00、首行缩进 4–8 格、段间距 0–4 档；滑杆点按走档、拖动实时预览、松手记住。页脚单行（页码 / 书名 / 百分比），页眉只留章节名。
- **书签**：底栏一键加/取消；目录内联展示，点条目跳转、× 删除。「我」页可导出/导入 JSON 在设备间合并（24 字容差去重），不上传任何数据。
- **划线**：长按 500ms 选字、拖动调范围，弹出「划线 / 想法」菜单；已划内容底色高亮，本地书与云端书均支持。
- **自动翻页**：进度面板设间隔（5–60 秒）后自动翻页，任意触摸即停。
- **进度双向同步**：开书拉取云端、关书回传本地（两个独立开关，默认关）。以「章节 uid + 章内偏移」定位（12 字容差），百分比兜底；云端快则跳转、本地快则上传、冲突时静默取新。离线翻页存快照，联网补传。
- **笔记**：阅读页顶部「笔记」进入覆盖页，含书籍卡片、我的书签、我的划线、书友想法入口。选中文字可写想法，发布走 `/web/review/add` 同步到官方 App（默认私密）。划线 range 换算失败时降级为仅本地，不打断阅读。
- **本地导入**：TXT / EPUB，自动分章、解析 OPF 元数据与封面、按 toc.ncx / nav 生成层级目录。Android 6+ 申请存储权限，被拒有授权引导；也可走 `content://` 通道免权限。离线模式只显示本地书。
- **书友想法**：按页拉取当前章想法（E-Ink 接口优先、网页兜底），可展开评论串。
- **设置与账号**：设置入口在书架右上角，分显示 / 阅读 / 账号三页。「我」页含阅读统计卡、数据与备份（整包 ZIP 备份恢复、书签导入导出）、E-Ink 授权、关于。

## 技术取舍

100% 代码直绘（无 XML 布局、无主题包，仅 5 个密度的 launcher 图标 PNG），只依赖一个 ZXing jar；黑白直绘无动画，`StaticLayout` 手动分页，界面图标全由 Canvas 现画。构建链：`javac --release 8` → R8 压缩脱糖 → aapt2 → zipalign → apksigner（V1 签名，兼容 Android 4.4 以下）。

低版本适配不是靠记忆：编译用 android-17 桩 jar，超界 API 直接编译不过；构建末步把 dex 里每个框架方法引用与 SDK `api-versions.xml` 比对，高于 minSdk 即失败；运行时权限用反射调用；TLS 提供兼容模式应对老 ROM 证书链残缺。

## 已知限制

- 不做语音朗读、内置字体切换、排行榜。
- 长章节（十万字级）首次排版有几百毫秒到一两秒停顿，属分页固有开销。
- 网页登录会过期，需重新扫码；书友想法依赖 E-Ink 授权，未授权处留空不编造数据。
- 书签同步是**手动导出/导入 JSON**，无云端自动同步（微信读书无公开书签接口）。
- 不支持调起本机微信 App 授权登录（需开放平台资质，且电纸书通常无微信）；现为屏上二维码扫码。
- 已验证竖屏模拟器与横屏电纸书真机；平板未适配。
